DESIGN PHILOSOPHY (What Makes It "Claude")
================================================================================

1. Warm Color Palette
   Light: #FAF9F5 (warm cream, not pure white)
   Dark:  #262624 (warm dark, not pure black)
   → Creates distinctive "Claude feel"

2. Message Asymmetry
   User: Right-aligned, filled background, rounded corners
   Assistant: Left-aligned, transparent, no border
   → Clearly differentiates speaker (visual hierarchy)

3. Generous Spacing
   8px grid base → breathing room without waste
   Messages separated at 24px (3 grids)
   → Conversational, not cramped

4. Inline Status Indicators
   Tool calls show status in-line (not separate popovers)
   Spinner, dot, checkmark all in the flow
   → User sees progress without UI interruption

5. Restrained Animation
   All <2s duration, smooth easing (ease-out, linear)
   Only subtle (fade, spin, pulse)
   → Modern feel without distraction

6. Semantic Color System
   Blue = info/action
   Green = success
   Orange = warning
   Red = error
   → Consistent with Claude's design system

7. No Shadows
   Depth via borders and background color only
   → Minimalist, not skeuomorphic

8. Accessibility by Design
   WCAG AA compliance from the start
   Focus states, touch targets, semantic HTML
   → Inclusive by default
