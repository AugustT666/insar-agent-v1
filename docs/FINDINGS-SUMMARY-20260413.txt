5. HARD CONSTRAINTS (D-InSAR Workflow)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Source: docs/agent-guide.md + skills/d-insar-isce2/SKILL.md

1. Reference & secondary from SAME relative orbit (same track)
2. Do NOT mix ascending/descending passes
3. Temporal baseline: 6–48 days (S-1 repeat = 12 days)
4. Orbit files required in orbit_dir; ISCE2 auto-downloads if online
5. Always run inside conda env: conda run -n isce2 python -m isce2.workflows.topsApp
6. Never manually edit topsApp.xml; use insar_set_processing_param API
7. DEM resolution reasonable (e.g., Copernicus 30m, not 1° SRTM)
8. Always invoke data-prep-sentinel first if inputs are raw SAFE/ZIP
9. ESD may fail in low-coherence → fallback to do_esd: False
10. Swath selection can reduce runtime (swaths: [2] vs [1,2,3])

7. KEY PARAMETERS (TOPS Single Pair)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Required:
  reference_safe       Path to reference SAFE or ZIP
  secondary_safe       Path to secondary SAFE or ZIP
  orbit_dir            Directory with POEORB orbit files
  dem_file             GeoTIFF DEM

Optional (Defaults shown):
  swaths: [1,2,3]      Process all 3 IW subswaths (or subset for speed)
  polarization: "vv"   VV or VH
  range_looks: 20      Multilook factor (range)
  azimuth_looks: 4     Multilook factor (azimuth)
  filter_strength: 0.5 Goldstein filter [0=off, 1=max]
  do_esd: True         Spectral diversity coregistration
  esd_coherence_threshold: 0.7   ESD floor
  unwrap_method: "snaphu"        or "icu"
  do_unwrap: True      or False for wrapped phase only
  do_unwrap_2stage: False
  bbox: None           [S, N, W, E] to crop (None = full swath)
  aux_dir: None        Auxiliary calibration files (optional)
