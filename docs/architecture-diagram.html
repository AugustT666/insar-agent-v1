① 白拿 · 零代码 FREE
共享 16 工具 · Project/Job · 统一输出树 自动继承。
唯一前提：所有产物走 resolve_output()，不自拼 output_dir。
② 适配器 · 必写 MUST
新增 engines/<engine>/adapter.py 实现 4 方法 → 在 engines/__init__ 注册。MCP 工具体一行不改。
③ 引擎模块 · 必写 MUST
engines/<engine>/：命令构建 · 参数模板/白名单 · 校验 · param-advisor 证据。照抄 isce2/isce3 结构，委托到自己模块。
④ 新工具 / skill · 可选 IF NEW
仅当引入现有工具表达不了的全新概念时才加，并在 PR 说明理由——避免膨胀 28 工具公共契约。

接入一个新引擎 · 流程清单

  1. 建引擎包 engines/<engine>/：命令构建 · 参数模板 · 校验 · 顾问证据 必写
  2. 实现 adapter.py：list_workflows / task_id_for / allowed_set_fields / required_fields 必写
  3. 注册：engines/__init__._ensure_builtin() 加 _REGISTRY["<engine>"] 必写
  4. 输出走 core.output_resolver.resolve_output，绝不自拼 output_dir 白拿
  5. 仅在必要时新增 MCP 工具 / skill，并在 PR 说明理由 可选
  6. 验证合规：运行下方两个守护测试
合规守护 · compliance gates
pytest tests/unit/test_engine_adapter_contract.py
