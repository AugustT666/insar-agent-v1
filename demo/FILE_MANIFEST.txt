📁 scripts/theme.js (113 lines, 4 KB)
────────────────────────────────────────────────────────────────────────────
PURPOSE: Light/dark theme toggle with localStorage persistence
FUNCTIONS:
  • getInitialTheme() — Check localStorage, then system preference, then default
  • applyTheme(theme) — Apply theme class to body, update icon, save to localStorage
  • toggleTheme() — Switch between light and dark modes
  • updateThemeIcon(theme) — Update moon/sun icon based on current theme
  • init() — Initialize on page load, attach event listeners
  • Event listener for system preference changes (respects user's OS dark mode toggle)

FEATURES:
  • Zero dependencies (vanilla JavaScript)
  • localStorage persistence (theme choice survives browser close)
  • System preference detection (prefers-color-scheme media query)
  • Auto-respects OS dark mode changes (unless user made explicit choice)
  • Theme icon changes: 🌙 in light mode (click to go dark), ☀️ in dark mode (click to go light)
  • No global variables (IIFE pattern)

USAGE: Linked in <body> of index.html (end of document)

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

Theme Not Persisting?
  → Check browser localStorage is enabled
  → Verify browser isn't in incognito/private mode
  → Check DevTools → Application → Local Storage → insar-demo-theme

Messages Not Rendering?
  → Verify file paths: styles/main.css and scripts/theme.js
  → Check browser console for 404 errors
  → Try opening from a local server instead of file:// protocol

Styling Looks Wrong?
  → Clear browser cache (Cmd+Shift+Delete / Ctrl+Shift+Delete)
  → Try different browser
  → Check CSS custom properties: :root { --color-bg-primary: ... }

Animations Stuttering?
  → Check browser DevTools Performance tab
  → Close other tabs (reduces memory pressure)
  → Try on faster CPU (animations use GPU transforms)

Accessibility Issues?
  → Use Chrome DevTools → Accessibility Inspector
  → Verify color contrast with WebAIM Contrast Checker
  → Check tab order with keyboard navigation
